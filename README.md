# Parking Lot System

A terminal-based Parking Lot Management System implemented in C++.

## Features

- Vehicle parking and exit
- Automatic parking spot allocation
- Parking fee calculation
- Parking availability tracking
- Vehicle and ticket search
- Configurable parking strategies
- Configurable pricing strategies
- Logging

## Design Patterns

- Factory
- Strategy
- Observer
- Singleton

## Technology

- C++
- STL
